Şifremi unuttum / yeni anahtarla kur

İlk kurulum. Panel siteye GitHub üzerinden yazar, bunun için bir kere GitHub anahtarı oluşturman lazım:

  1. GitHub'da yeni anahtar sayfasını aç.
  2. Token name: suatilyus panel · Expiration: 1 yıl.
  3. Repository access: Only select repositories → suatilyus.github.io
  4. Permissions → Repository → Contents: Read and write.
  5. Generate token'a bas, çıkan github_pat_… yazısını aşağıya yapıştır.

Sonra kendine bir müdüriyet şifresi belirle. Başka cihazlarda sadece bu şifreyle girersin. En az 10 karakter olsun, kolay tahmin edilmesin.

Anahtar şifrelenip sitede saklanır; şifren olmadan açılamaz. Şifreyi ve anahtarı kimseyle paylaşma.
